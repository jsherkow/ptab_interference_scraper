## Current Architecture

### Key Technical Discoveries

1. **AG Grid Component**: The USPTO site uses AG Grid (not standard HTML tables)
   - Data is in `.ag-row` elements with `.ag-cell` children
   - Headers are in `.ag-header-cell-text` elements
   - Must wait for JavaScript to render the grid after page load
   - Two main sections: `#papersSection` and `#exhibitsSection`

2. **Loading Strategy**: 
   - Use `networkidle2` wait condition (less strict than `networkidle0`)
   - Poll for `ag-grid-angular` elements to appear (usually ~1 second)
   - Additional 3-second wait for data population
   - Total page load time: ~4-5 seconds

3. **Data Structure**:
   - **Papers**: Paper #, Filing date, Paper type, Document name, Pages, Filing party, Availability
   - **Exhibits**: Exhibit/Document #, Filing date, Document name, Pages, Filing party, Availability
   - Documents have clickable links (`<a>` tags) within cells for downloading

4. **Document Link Mechanism** (CRITICAL DISCOVERY):
   - Document links are NOT traditional `<a href="...">` links
   - Links are Angular components (`<app-open-document>`) with click handlers
   - Clicking a link calls `window.open(url)` to open PDF in new tab
   - The URL is dynamically generated and contains a unique `artifactId` parameter
   - **Solution**: Intercept `window.open()` calls by injecting JavaScript before page load
   - Pattern: `https://ptacts.uspto.gov/interferences/public-informations/petitions/<petition_id>/download-documents?artifactId=<unique_id>`

5. **Browser Configuration for Link Capture**:
   - Must use `--disable-popup-blocking` flag to allow `window.open()` interception
   - Inject interceptor with `page.evaluateOnNewDocument()` BEFORE navigation
   - Store captured URLs in `window.capturedUrls` array
   - Click simulation triggers the Angular handler which calls `window.open()`
   - No new tab actually opens in headless mode, but URL is captured
   - Wait ~300ms after click for JavaScript to execute

### Async/Await Pattern

Since Pyppeteer is async-based, use async/await throughout:

```python
import asyncio
from pyppeteer import launch

async def main():
    browser = await launch(headless=True, args=['--no-sandbox', '--disable-setuid-sandbox'])
    page = await browser.newPage()
    
    try:
        await page.goto(url, {'waitUntil': 'networkidle2', 'timeout': 60000})
        # ... scraping logic
    finally:
        await browser.close()

if __name__ == "__main__":
    asyncio.run(main())
```

### Code Example - URL Extraction (WORKING SOLUTION)

The key discovery is that document links use Angular click handlers that call `window.open()`, not traditional href attributes. Here's the working approach:

```python
# 1. Inject window.open interceptor BEFORE page loads
await page.evaluateOnNewDocument('''() => {
    window.capturedUrls = [];
    const originalOpen = window.open;
    window.open = function(...args) {
        console.log('window.open called with URL:', args[0]);
        window.capturedUrls.push(args[0]);
        return originalOpen.apply(this, args);
    };
}''')

# 2. Navigate to page
await page.goto(url, {'waitUntil': 'networkidle2', 'timeout': 60000})

# 3. For each document, clear array and click the link
await page.evaluate('window.capturedUrls = []')

await page.evaluate(f'''() => {{
    const papersSection = document.getElementById('papersSection');
    const rows = papersSection.querySelectorAll('.ag-row');
    const row = rows[{index}];
    const link = row.querySelector('app-open-document a');
    if (link) link.click();
}}''')

# 4. Wait briefly and retrieve captured URL
await asyncio.sleep(0.3)
captured = await page.evaluate('window.capturedUrls')
download_url = captured[0] if captured else None
```

**Important**: 
- Use `--disable-popup-blocking` browser argument
- Inject interceptor with `evaluateOnNewDocument()` before navigation
- URLs have format: `https://ptacts.uspto.gov/interferences/public-informations/petitions/1553387/download-documents?artifactId=<unique_id>`

## Troubleshooting

### Chromium Installation Issues

If Pyppeteer can't find Chromium:
```bash
uv run python -m pyppeteer install
```

### Timeout Errors

Increase timeout values in scraper configuration:
```python
await page.goto(url, {'timeout': 60000})  # 60 seconds
```

### AG Grid Not Loading

If the grid doesn't populate:
- Increase wait time after page load (currently 3 seconds)
- Check if USPTO site structure changed
- Verify network connectivity
- Try running in headed mode to visually inspect: `headless=False`

### Memory Issues with Large Cases

For cases with many documents:
- Process in batches
- Clear browser cache between downloads
- Use a single browser instance but create new pages
- Consider pagination if AG Grid supports it

## Common Pitfalls to Avoid

1. **Not cleaning up browser instances**: Always use try/finally blocks
2. **Hardcoding wait times**: Use dynamic waits when possible (waitForSelector)
3. **Ignoring rate limiting**: Don't hammer the USPTO server
4. **Poor error messages**: Always include context (case number, document name, etc.)
5. **Assuming consistent structure**: The website may change; write defensive code
